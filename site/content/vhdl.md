VHDL is a hardware description language used to describe digital logic at the level of individual registers and logic structures, which is the source of the fine control that makes programmable logic worth using.<sup><a href="#ref-150" data-tip="Ep 150: Solar, FPGAs and Maxim Integrated - Solar Shopper Sickness (June 17, 2013)" title="Ep 150: Solar, FPGAs and Maxim Integrated - Solar Shopper Sickness (June 17, 2013)">[150]</a></sup> It is strongly typed and explicit, requiring a signal to be stated in effectively three places with all of them matching, and the tool reports at length when they do not.<sup><a href="#ref-469" data-tip="Ep 469: An Interview with Craig J Bishop (December 1, 2019)" title="Ep 469: An Interview with Craig J Bishop (December 1, 2019)">[469]</a></sup> That redundancy is the direct cause of the language's verbosity and also removes an entire class of defect before simulation, since a mistyped identifier stops the tool rather than silently producing an additional object.<sup><a href="#ref-449" data-tip="Ep 449: Pulled From A Working Environment (June 30, 2019)" title="Ep 449: Pulled From A Working Environment (June 30, 2019)">[449]</a></sup><sup><a href="#ref-469" data-tip="Ep 469: An Interview with Craig J Bishop (December 1, 2019)" title="Ep 469: An Interview with Craig J Bishop (December 1, 2019)">[469]</a></sup> The VHDL and Verilog abstraction has held as a universal standard across decades of process and vendor change: RTL written without vendor-specific IP blocks can be pushed through different vendors' FPGA flows and, with care, through an ASIC flow without modification.<sup><a href="#ref-650" data-tip="Ep 650: Accessible ASICs with Andreas Olofsson (November 12, 2023)" title="Ep 650: Accessible ASICs with Andreas Olofsson (November 12, 2023)">[650]</a></sup>

## Verbosity and strictness

VHDL requires substantially more syntax and boilerplate than Verilog for the same design. In textbooks that print equivalent implementations side by side, the Verilog page is around ninety per cent white space while the VHDL page fills entirely.<sup><a href="#ref-303" data-tip="Ep 303: An Interview with Dmitry Nedospasov (June 14, 2016)" title="Ep 303: An Interview with Dmitry Nedospasov (June 14, 2016)">[303]</a></sup> The additional capability VHDL offers in some respects is paid for in declaration duplication, the same information restated in several places, and that duplication is the specific reason engineers who want C-like syntax use Verilog instead.<sup><a href="#ref-325" data-tip="Ep 325: An Interview with David Kronstein (Tesla500) (November 30, 2016)" title="Ep 325: An Interview with David Kronstein (Tesla500) (November 30, 2016)">[325]</a></sup>

The strictness has a compensating effect. VHDL will not accept a name that has not been declared and matched everywhere it appears, so a typo in a signal identifier halts the tool at that point rather than propagating into synthesis.<sup><a href="#ref-449" data-tip="Ep 449: Pulled From A Working Environment (June 30, 2019)" title="Ep 449: Pulled From A Working Environment (June 30, 2019)">[449]</a></sup> The result is a language that is slow to write and correspondingly hard to write wrongly.

Verbosity is not the same as low expressiveness. With the right macros and abstractions in place, an entire microcontroller can be described in a couple of hundred lines of VHDL that another engineer can read through and recognise as a processor, which matters because hardware description source is read far more often than it is written.<sup><a href="#ref-181" data-tip="Ep 181: An Interview with Dave Vandenbout - Xceptional XESS Xenagogue" title="Ep 181: An Interview with Dave Vandenbout - Xceptional XESS Xenagogue">[181]</a></sup>

## The delta cycle

The delta cycle is a VHDL feature governing the state analysis of how concurrent processes interact within a simulation time step; Verilog implements the same idea differently.<sup><a href="#ref-237" data-tip="Ep 237: An Interview with Joe and Mark Garrison - Subtly Spelling SayLeeAy (February 17, 2015)" title="Ep 237: An Interview with Joe and Mark Garrison - Subtly Spelling SayLeeAy (February 17, 2015)">[237]</a></sup> Understanding it is the dividing line in a designer's competence, since the error rate in written code drops sharply once the model is internalised.<sup><a href="#ref-237" data-tip="Ep 237: An Interview with Joe and Mark Garrison - Subtly Spelling SayLeeAy (February 17, 2015)" title="Ep 237: An Interview with Joe and Mark Garrison - Subtly Spelling SayLeeAy (February 17, 2015)">[237]</a></sup>

## Verification

VHDL was built to support verification to a degree Verilog's syntax does not allow, extending to theoretical proofs that a piece of hardware will function as specified.<sup><a href="#ref-303" data-tip="Ep 303: An Interview with Dmitry Nedospasov (June 14, 2016)" title="Ep 303: An Interview with Dmitry Nedospasov (June 14, 2016)">[303]</a></sup> The practical consequence is a mixed-language division of labour in which the design itself is written in Verilog and the test benches are written in VHDL.<sup><a href="#ref-303" data-tip="Ep 303: An Interview with Dmitry Nedospasov (June 14, 2016)" title="Ep 303: An Interview with Dmitry Nedospasov (June 14, 2016)">[303]</a></sup> The two languages coexist inside a single project with a designer using both at once, though a VHDL test bench carries over to a different target's tool set only partially, so verification effort does not fully transfer when a design moves from FPGA to gate array.<sup><a href="#ref-147" data-tip="Ep 147: An interview with Jeri Ellsworth - Absorptive Augmented Actuality (May 27, 2013)" title="Ep 147: An interview with Jeri Ellsworth - Absorptive Augmented Actuality (May 27, 2013)">[147]</a></sup>

The language also supports a purely software-side career in hardware: some practitioners work only in the simulated domain, writing test benches and algorithms, and never take a design to physical hardware.<sup><a href="#ref-83" data-tip="Ep 83: Aggravating Agersia Agiotage (February 19, 2012)" title="Ep 83: Aggravating Agersia Agiotage (February 19, 2012)">[83]</a></sup>

## Where VHDL is used

VHDL usage follows a geographic and sector split rather than a technical one: it predominates east of the Mississippi and across Europe, while Verilog predominates on the United States west coast and in Asia, and military work is largely VHDL.<sup><a href="#ref-181" data-tip="Ep 181: An Interview with Dave Vandenbout - Xceptional XESS Xenagogue" title="Ep 181: An Interview with Dave Vandenbout - Xceptional XESS Xenagogue">[181]</a></sup> VHDL was the default language for FPGA work through roughly the mid-2000s, and the balance has since moved, with chip industry work now predominantly Verilog and VHDL retaining a substantial minority of it rather than disappearing.<sup><a href="#ref-449" data-tip="Ep 449: Pulled From A Working Environment (June 30, 2019)" title="Ep 449: Pulled From A Working Environment (June 30, 2019)">[449]</a></sup> In the first Tiny Tapeout run, roughly thirty to forty per cent of submitted designs were written in a hardware description language, and the submission flow had to be split into separate automated build paths for Verilog, Amaranth and VHDL, since a shared entry point could not cover all three.<sup><a href="#ref-616" data-tip="Ep 616: Open Source Tapeout with Matthew Venn (January 22, 2023)" title="Ep 616: Open Source Tapeout with Matthew Venn (January 22, 2023)">[616]</a></sup>

Language choice among users of a development board is set by the language of the supplied example code rather than by the users' own evaluation: a vendor providing all of its examples in VHDL sees its customers converge on VHDL.<sup><a href="#ref-181" data-tip="Ep 181: An Interview with Dave Vandenbout - Xceptional XESS Xenagogue" title="Ep 181: An Interview with Dave Vandenbout - Xceptional XESS Xenagogue">[181]</a></sup> At the opposite end of the scale, very low gate-count programmable logic parts are configured through a graphical design entry tool in which lookup tables and flip-flops are dragged, dropped and wired up, because at that gate count the effort of a hardware description language buys nothing.<sup><a href="#ref-65" data-tip="Ep 65: Silego, ADCs & Seismic Detection - Dave's Dingo Dystocia" title="Ep 65: Silego, ADCs & Seismic Detection - Dave's Dingo Dystocia">[65]</a></sup>

A large offshore supply of VHDL coding labour exists, sustained by graduate volume, competing on hourly rate and turnaround; the countervailing cost is quality, since cheap logic that has to be limped along and supported afterwards can outweigh the saving on hours.<sup><a href="#ref-70" data-tip="Ep 70: Idiorhythmic IPC Inconcinnity" title="Ep 70: Idiorhythmic IPC Inconcinnity">[70]</a></sup> Programmable logic distributors also staff field application engineers with FPGA expertise who will write VHDL for a customer to get a design running, which is how companies without in-house FPGA skill obtain it.<sup><a href="#ref-116" data-tip="Ep 116: Distribution, Wozniak & Robots - Early Eight-bit Endgame (October 7, 2012)" title="Ep 116: Distribution, Wozniak & Robots - Early Eight-bit Endgame (October 7, 2012)">[116]</a></sup>

## Learning and moving between languages

Becoming able to program in VHDL is a formal-learning task measured in weeks of concentrated effort, unlike the incremental daily accumulation of engineering knowledge from reading and browsing.<sup><a href="#ref-256" data-tip="Ep 256: Is This A Show? (July 1, 2015)" title="Ep 256: Is This A Show? (July 1, 2015)">[256]</a></sup> Free vendor toolchains from Xilinx, Altera, Lattice and Actel are sufficient to learn on and ship extensive tutorials with the software; for experience that carries commercial value the recommendation is to learn on one of the two large vendors' toolchains rather than a minor one.<sup><a href="#ref-103" data-tip="Ep 103: An Interview with Philip Freidin - Xenodochial Xilinx Ex-Employee (July 8, 2012)" title="Ep 103: An Interview with Philip Freidin - Xenodochial Xilinx Ex-Employee (July 8, 2012)">[103]</a></sup>

The gap to Verilog is syntactic rather than conceptual, and an engineer fluent in Verilog can write working VHDL with reference material to hand.<sup><a href="#ref-303" data-tip="Ep 303: An Interview with Dmitry Nedospasov (June 14, 2016)" title="Ep 303: An Interview with Dmitry Nedospasov (June 14, 2016)">[303]</a></sup> Moving in the other direction is equally practical on a deadline: an engineer trained in Verilog was moved onto a VHDL product and shipped it within about three months, learning by doing, and the VHDL content of successive digital test instrument cards was largely similar, covering streaming data to and from the host CPU, constructing test patterns, and checking for errors in responses.<sup><a href="#ref-138" data-tip="Ep 138: An Interview with Ryan Brown - Effortless Equipment Extensibility (March 25, 2013)" title="Ep 138: An Interview with Ryan Brown - Effortless Equipment Extensibility (March 25, 2013)">[138]</a></sup>

Migration away from VHDL is driven by tool and library availability. Open-source FPGA toolchains support Verilog more thoroughly, and the stock of existing example code and reusable cores is larger in Verilog, so choosing VHDL narrows the available tools and reference designs; VHDL cores do exist but in smaller number, and engineers who began in VHDL commonly switch when they start working with United States companies or on open-source projects.<sup><a href="#ref-467" data-tip="Ep 467: Stories from Supercon 2019 (November 18, 2019)" title="Ep 467: Stories from Supercon 2019 (November 18, 2019)">[467]</a></sup>

## Generated VHDL

The register level becomes a liability for arithmetic-heavy work such as DSP, where hand-coding every function at register level each time is avoided in favour of a generator that emits the VHDL.<sup><a href="#ref-150" data-tip="Ep 150: Solar, FPGAs and Maxim Integrated - Solar Shopper Sickness (June 17, 2013)" title="Ep 150: Solar, FPGAs and Maxim Integrated - Solar Shopper Sickness (June 17, 2013)">[150]</a></sup> A common DSP path into programmable logic never has the engineer writing the hardware description at all: the algorithm is built as a block model in Simulink, the model is converted to VHDL, and the VHDL is pushed into the FPGA, with Simulink sitting at a much higher abstraction level than C so that the effective design language is the block diagram.<sup><a href="#ref-150" data-tip="Ep 150: Solar, FPGAs and Maxim Integrated - Solar Shopper Sickness (June 17, 2013)" title="Ep 150: Solar, FPGAs and Maxim Integrated - Solar Shopper Sickness (June 17, 2013)">[150]</a></sup> FPGA blocksets for Simulink, sold from around 2004 by Synplify and by Xilinx, let a designer assemble a math model graphically and emit VHDL or Verilog from it; the generated code makes the flow usable by an engineer who does not know the language well, but it is not maintainable source, so the model rather than the VHDL becomes the artefact that must be kept.<sup><a href="#ref-264" data-tip="Ep 264: The Cost Of Doing Business (August 25, 2015)" title="Ep 264: The Cost Of Doing Business (August 25, 2015)">[264]</a></sup> Migen serves a similar role from a different direction, a Python toolbox for building complex digital hardware that functions as a Python-to-VHDL compiler, generating the hardware description from a higher-level program rather than replacing the downstream flow.<sup><a href="#ref-428" data-tip="Ep 428: Setting Fire To The Tracks (February 3, 2019)" title="Ep 428: Setting Fire To The Tracks (February 3, 2019)">[428]</a></sup>

## Design practice

When a VHDL design does not fit the target device, the two options are a larger FPGA or optimisation of the description itself; a logic analyser design that initially fitted only two channels was optimised rather than moved to a bigger part, over roughly four months of work before it fitted.<sup><a href="#ref-237" data-tip="Ep 237: An Interview with Joe and Mark Garrison - Subtly Spelling SayLeeAy (February 17, 2015)" title="Ep 237: An Interview with Joe and Mark Garrison - Subtly Spelling SayLeeAy (February 17, 2015)">[237]</a></sup>

VHDL frequently occupies a defined slot within a partitioned system rather than the whole device. One commercial FPGA module platform reserves fixed vendor IP for the bus interface and DRAM, leaves a window for high-level graphical code, and leaves a second window for user VHDL that interfaces to the analogue circuit; the user's VHDL is the low-level layer that configures the clocking chip, monitors temperature and captures ADC data, and the vendor documents the timing and mechanical constraints for it in a module developer kit.<sup><a href="#ref-138" data-tip="Ep 138: An Interview with Ryan Brown - Effortless Equipment Extensibility (March 25, 2013)" title="Ep 138: An Interview with Ryan Brown - Effortless Equipment Extensibility (March 25, 2013)">[138]</a></sup> Vendor instrumentation is delivered the same way: a plugin instantiated in the user's VHDL taps the FPGA die's 10 Gbit transceiver and streams the raw recovered data to a PC application that computes average and peak bit error rate over days of running; every parameter is tweakable, so the same setup can be tuned until almost any link passes, and results are only meaningful with the tweaks and the temperature stated.<sup><a href="#ref-148" data-tip="Ep 148: Contextual Electronics, ClubJameco and Solderpaste - Lifelong Learning Likelihood (June 3, 2013)" title="Ep 148: Contextual Electronics, ClubJameco and Solderpaste - Lifelong Learning Likelihood (June 3, 2013)">[148]</a></sup>

An open soft core distributed as VHDL source, such as the ZPUino, serves as an alternative to a vendor's own processor core, whose tooling is closed and not available to modify without a full licence.<sup><a href="#ref-232" data-tip="Ep 232: Impedance Matching&quot; with Davidson and Vandenbout - Presbytes Pushing Portfolios" title="Ep 232: Impedance Matching&quot; with Davidson and Vandenbout - Presbytes Pushing Portfolios">[232]</a></sup> Because the source is open, custom peripherals slide into the core easily: a simple RGB LED controller added as a peripheral generates the PWM waveforms continuously in logic, so the processor only pokes it occasionally instead of driving the waveforms itself.<sup><a href="#ref-232" data-tip="Ep 232: Impedance Matching&quot; with Davidson and Vandenbout - Presbytes Pushing Portfolios" title="Ep 232: Impedance Matching&quot; with Davidson and Vandenbout - Presbytes Pushing Portfolios">[232]</a></sup> Legacy processor cores can likewise be reimplemented from the ground up in VHDL and shipped in silicon without royalty exposure where the relevant patents have lapsed or the core was released — the 6502's instruction-set and mnemonic patents have long expired and Intel placed the 8051 in the public domain — whereas embedding an ARM core costs a per-unit royalty or a fixed fee negotiated up front for very large volumes.<sup><a href="#ref-169" data-tip="Ep 169: An Interview with Vincent Himpe - Escaped Electron Elocution (October 28, 2013)" title="Ep 169: An Interview with Vincent Himpe - Escaped Electron Elocution (October 28, 2013)">[169]</a></sup>
